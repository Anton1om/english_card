# EnglishCard

Веб-приложение для изучения английских слов с помощью интерактивных карточек и викторины.  

---

## Возможности

- **Авторизация** по имени пользователя (без пароля)
- **Изучение слов** – показывается слово, нужно выбрать правильный перевод из четырёх вариантов
- **Добавление своих слов** – с возможностью автоматического подбора перевода
- **Удаление персональных слов** – можно удалять только те слова, которые добавил пользователь
- **Статистика** – количество правильных/неправильных ответов по каждому слову и общая точность

## Быстрый старт

### Предварительные требования
- Python 3.10+
- PostgreSQL 14+


### Установка и настройка

#### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Anton1om/english_card.git
cd english_card
```
#### 2. Создайте и активируйте виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # для Windows
```    
#### 3. Установите зависимости
```bash
pip install -r requirements.txt
```
#### 4. Настройте переменные окружения
Скопируйте файл .env.example в .env и заполните его:

```env
# Подключение к PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=english_card
DB_USER=postgres
DB_PASSWORD=<пароль к пользователю postgres>

# Ключ для Яндекс.Словаря (Опционально. Можно получить здесь https://yandex.ru/dev/dictionary/keys/get/?service=dict)
YANDEX_TRANSLATE_TOKEN=dict.1.1.xxxxx
```
#### 5. Создайте базу данных в PostgreSQL
```sql
CREATE DATABASE english_card;
```
#### 6. Запустите приложение
``` bash
streamlit run main.py
```
При первом запуске таблицы и начальный набор слов создадутся автоматически. При необходимости можно инициализировать БД вручную
``` bash
python init_db.py
```

### Структура проекта
 - main.py – точка входа, сборка интерфейса. 
 - ui.py – все элементы Streamlit (вкладки, панели).
 - db.py – работа с БД (CRUD-операции).
 - logic.py – бизнес-логика (генерация вариантов, работа с API). 
 - init_db.py – инициализация схемы и начальных данных. 
 - config.py – загрузка переменных окружения. 
 - sql/ – SQL-скрипты для создания таблиц и заполнения общими словами. 
 - assets/ – изображения для README и интерфейса.

---

### Дополнительно
Автоматический перевод работает через Яндекс.Словарь.  Это необязательная опция, и приложение будет функционировать и без неё. Подробнее о сервисе и получении ключа можно узнать [здесь](https://yandex.ru/dev/dictionary)
